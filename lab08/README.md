## Ответы на вопросы

### Почему запись удобно представить словарём?

Словарь позволяет обращаться к полям по осмысленным именам (`record["title"]`),
а не по индексам, как в кортеже. Это делает код самодокументируемым: сразу видно,
что означает каждое значение. Кроме того, словарь легко расширять — можно добавить
новое поле (`completed`) без изменения структуры остальных записей. В списке словарей
каждая запись остаётся независимой, и порядок полей не важен.

### Как работает `.get(key, default)`?

Метод `dict.get(key, default)` возвращает значение по ключу `key`, если он есть в словаре.
Если ключа нет — возвращает `default` (и не бросает `KeyError`). В нашем коде
`counts.get(cleaned, 0) + 1` означает: «если слова ещё нет — считаем, что его было 0,
и прибавляем 1». Это короче и безопаснее, чем проверка `if cleaned in counts`.

### Почему множество нужно сортировать перед выводом?

Множество (`set`) в Python — неупорядоченная коллекция: порядок элементов при обходе
не определён и может меняться между запусками. Чтобы получить стабильный,
предсказуемый и удобный для чтения результат (по алфавиту), мы явно сортируем
множество через `sorted(...)`, который возвращает список.

### Дополнительное задание

`sorted_totals(records)` возвращает список пар `(category, total)`, отсортированных:
