## Задание 3. Предскажите результат
Мои вычесления

2 + 3 * 4 = 14 ;
(2 + 3) * 4 = 20 ;
17 // 5 = 3 ;
17 % 5  = 2 ;
-7 // 2 = -3 .


Python

print(2 + 3 * 4)     # 14 ; 
print((2 + 3) * 4)   # 20 ; 
print(17 // 5)       # 3 ; 
print(17 % 5)        # 2 ; 
print(-7 // 2)       # -4 .

Прогноз почти полностью совпал с результатами Python.

В выражении 2 + 3 * 4 сначала выполняется умножение, поэтому результат равен 14.
В выражении (2 + 3) * 4 сначала выполняется действие в скобках, поэтому результат равен 20.
Оператор // выполняет целочисленное деление с округлением вниз: 17 // 5 = 3.
Оператор % возвращает остаток от деления: 17 % 5 = 2.
В выражении -7 // 2 результат равен -4, потому что -7 / 2 = -3.5, а целочисленное деление // округляет результат. Однако если брать целую часть от -7//2 это будет-3


## Индивидуальный вариант №5 

### Как запустить
```
python variant.py
```
Ввести два целых неотрицательных числа: общий объём и положительную вместимость единицы.

### Формулы
- полных единиц: `total // capacity`
- остаток: `total % capacity`
- минимальное число единиц: `(total + capacity - 1) // capacity`

### Проверка 1 (есть остаток)
**Ввод:** `total = 23`, `capacity = 5`

**Ручной прогноз:**
- полных команд: `23 // 5 = 4`
- остаток: `23 % 5 = 3`
- минимум единиц: `(23 + 5 − 1) // 5 = 27 // 5 = 5`

**Ожидалось:** `4`, `3`, `5`
**Получено:** `4`, `3`, `5` ✅

### Проверка 2 (ровно делится)
**Ввод:** `total = 20`, `capacity = 5`
- полных: `4`, остаток: `0`, минимум: `(20 + 4) // 5 = 4`

**Ожидалось:** `4`, `0`, `4`
**Получено:** `4`, `0`, `4` ✅

### Проверка 3 (нулевой объём)
**Ввод:** `total = 0`, `capacity = 5`
- полных: `0`, остаток: `0`, минимум: `(0 + 4) // 5 = 0`

**Ожидалось:** `0`, `0`, `0` (по условию при нулевом объёме последнее число равно нулю)
**Получено:** `0`, `0`, `0` ✅

### Проверка 4 (объём меньше вместимости)
**Ввод:** `total = 3`, `capacity = 10`
- полных: `0`, остаток: `3`, минимум: `(3 + 9) // 10 = 1`

**Ожидалось:** `0`, `3`, `1`
**Получено:** `0`, `3`, `1` ✅
