Мои вычесления

2 + 3 * 4 = 14
(2 + 3) * 4 = 20
17 // 5 = 3
17 % 5  = 2
-7 // 2 = -4


Python

print(2 + 3 * 4)     # 14
print((2 + 3) * 4)   # 20
print(17 // 5)       # 3
print(17 % 5)        # 2
print(-7 // 2)       # -4

Прогноз почти полностью совпал с результатами Python.

В выражении 2 + 3 * 4 сначала выполняется умножение, поэтому результат равен 14.
В выражении (2 + 3) * 4 сначала выполняется действие в скобках, поэтому результат равен 20.
Оператор // выполняет целочисленное деление с округлением вниз: 17 // 5 = 3.
Оператор % возвращает остаток от деления: 17 % 5 = 2.
В выражении -7 // 2 результат равен -4, потому что -7 / 2 = -3.5, а целочисленное деление // округляет результат. Однако если брать целую часть от -7//2 это будет-3
