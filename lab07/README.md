# Лабораторная работа: Функции и модули (Вариант 5)

## Структура проекта
- `functions.py` — модуль с реализацией функций (без ввода/вывода).
- `main.py` — скрипт для интерактивной демонстрации работы функций.
- `test_functions.py` — модуль с автоматическими проверками (assert-тесты).

## Команды запуска
1. Интерактивный запуск основной программы:
   ```bash
   python main.py
2. Запуск автоматических проверок (тестов):
   ```bash
   python test_functions.py
