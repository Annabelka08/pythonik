# Лабораторная работа: списки и встроенные функции

## Структура
- `statistics.py` — статистика по списку целых чисел.
- `transform.py` — независимое преобразование (модули отрицательных) + удаление повторов.
- `positions.py` — индексы всех максимумов.
- `variant.py` — индивидуальный вариант 5 (положительные числа).

Каждая программа читает целые числа одной строкой из стандартного ввода.

## Команды запуска
```bash
python statistics.py
python transform.py
python positions.py
python variant.py
