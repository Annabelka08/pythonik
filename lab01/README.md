| Позиция 2 | Скакалки — 6 шт × 120.50 |
| Доставка | 300.00 |
| Внесено | 2500.00 |
| Скидка | 10 % |

### Ручной расчёт (до запуска)

1. Мячи: `4 × 350.00 = 1400.00`
2. Скакалки: `6 × 120.50 = 723.00`
3. Товары без доставки: `1400.00 + 723.00 = 2123.00`
4. Скидка: `2123.00 × 10 / 100 = 212.30`
5. Товары со скидкой: `2123.00 − 212.30 = 1910.70`
6. Итого с доставкой: `1910.70 + 300.00 = 2210.70`
7. Всего единиц: `4 + 6 = 10`
8. Сдача: `2500.00 − 2210.70 = 289.30`

## Объяснения ключевых понятий

### Различие строки и числа

- **Строка (`str`)** — последовательность символов. Оператор `+` для строк выполняет **конкатенацию**: `"2" + "3" = "23"`.
- **Число (`int`, `float`)** — числовое значение. Оператор `+` выполняет **арифметическое сложение**: `2 + 3 = 5`.
- `input()` всегда возвращает строку. Чтобы работать с числом, нужны `int(...)` или `float(...)`.
- В фрагментах А и Б ошибка возникала именно из-за того, что данные оставались строками: в А — конкатенация вместо суммы, в Б — `TypeError` при `str + int`.

### Порядок вычислений

- В Python приоритет: `*`, `/`, `//`, `%` — **выше**, чем `+` и `-`.
- Скобки **переопределяют** порядок: `(2 + 3) * 4 = 20`, а `2 + 3 * 4 = 14`.
- В фрагменте В без скобок `first + second + third / 3` выполнялось как `4 + 7 + (10 / 3) ≈ 14.33`. Скобки `(first + second + third) / 3` дают правильное среднее `7.0`.

### Назначение временной переменной при обмене

- Чтобы поменять значения двух переменных, нужно **сохранить** одно значение, иначе оно будет потеряно.
- Алгоритм: `temp = a; a = b; b = temp`.
- Без `temp` присваивание `a = b` затрёт исходное `a`, и обмен не состоится.
- Множественное присваивание `a, b = b, a` делает то же самое, но по заданию его использовать нельзя — поэтому применяется третья переменная.

### Форматирование денежного вывода

- Используется f-строка с форматом `.2f`: `f"{value:.2f}"`.
- `.2f` означает: **2 знака после десятичной точки**, округление по правилам Python.
- Пример: `2123.0 → "2123.00"`, `120.5 → "120.50"`.
- Это гарантирует единообразный вид денежных значений в выводе.
