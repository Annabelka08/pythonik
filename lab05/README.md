# Лабораторная работа: Строки

## Структура проекта
- `normalize.py` — нормализация текста (удаление лишних пробелов).
- `palindrome.py` — проверка на палиндром.
- `replace.py` — замена символов с подсчётом.
- `variant.py` — индивидуальный вариант 15 (фильтрация слов по первой букве).

## Команды запуска
```bash
python normalize.py
python palindrome.py
python replace.py
python variant.py
